# ScarLoade# 🚀 ScarLoader

**ScarLoader** is a Roblox script loader designed to make loading your favorite menus simple, fast, and convenient.

## ✨ Features

- 🔓 **Free & Premium** versions available
- ⚡ Fast script loading
- 🛡️ Load menus directly from Roblox without downloading random files
- 📦 Simple and user-friendly interface
- 🔄 Regular updates and improvements

## 📋 Available Menus

ScarLoader currently supports:

- 🌑 ScarShade
- 📋 PlinkBoard Menu
- 🪐 Zorbit
- 💎 Ultri

More menus will be added over time.

## ⭐ Why ScarLoader?

Instead of searching for scripts across different websites or downloading files from unknown sources, ScarLoader lets you access supported menus from one place. It's built to provide a cleaner, easier loading experience for users.

## 💎 Versions

### Free
- Access to supported free menus
- Basic features
- Regular updates

### Premium
- Access to all premium-supported menus
- Faster updates
- Exclusive features
- Priority support
